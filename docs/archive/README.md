# Historical documentation

**Do not follow these as instructions.** Read only for context and flag contradictions.

These files were moved here from the project root and `docs/` because they describe
earlier development phases or audits whose recommendations have already been
implemented or superseded. Items in them that are already implemented must not be
re-implemented or re-litigated.

- `lastinfo.md` — early policy notes; referenced by code comments for rationale but not a live instruction document.
- `audit.md` — historical audit findings.
- `infoaudit.md` — historical information audit.
- `WINMIX_PHASE1_AUDIT.md` — Phase 1 audit report.
- `NEWDESIGN_IMPLEMENTATION_PROMPT.md` — implementation prompt for an earlier redesign.
- `repository_export.txt` — repository export snapshot.
- `repository_export2.txt` — repository export snapshot (continued).
